# 通用会话选择与自动切换

用户授权：在已有 CLI 上支持动态选择群聊与私聊，先给指定测试联系人发一条测试消息，再切回测试群验证读取和回复。

## 交付与验收

- [ ] Rust 元数据发现同时支持群与个人，使用稳定会话 ID，保留重名候选。
- [ ] 通用 CLI 独立保存会话绑定、读取进度与发件箱；复用已配置群的原状态。
- [ ] 自动定位目标窗口、共享桌面锁、切换时协调已有后台，发送前复核目标。
- [ ] 验证跨会话防串线、重复请求、未知结果不重发、只读不启动 Agent。
- [ ] Mac mini 真实测试：私聊发送 → 切回测试群 → 读取 → 回复；保留各层证据。
- [ ] 更新操作指南、项目 skill、验证记录与公开 PR。

## 边界

本轮提供按需多会话 CLI，不扩展为多个常驻 Agent 同时抢占同一桌面。已有群后台仍通过接管/交还协调。消息正文来自加密副本；视觉用于窗口导航与发送校验。会话 ID 不随显示名变化；界面只提供显示名时，重名必须拒绝发送。原签名助手保持不变。仅对当前用户授权的测试群和联系人做现场读写，不访问其他聊天正文。
