# 交互 CLI 验证记录 · 2026-10-16

本轮验证 `wx-agent` 0.2.0 的 skill + CLI 选群、读取、回复、接管和交还。单个已配置的授权测试群；不是多群上线或长期稳定性结论。本文不保存真实账号、群 ID、聊天正文、部署配置或截图。

## 工程验证

- Rust：`cargo fmt --check`、全目标 clippy（警告视为失败）、`cargo test --locked` 通过。仓库原有忽略测试仍保持忽略，不能算作已执行。
- 合成数据 CLI 回归：1,100 条积压、迟到消息、修改事件、去重和重启消费位置检查通过；源文件未被读取路径修改。该测试不使用真实微信。
- Python：63 项脚本测试通过；0.2.0 wheel 在源码之外安装后的 31 项包测试通过，覆盖 Python 3.10、3.12，以及 Mac mini 的 Python 3.9.6。实机私有安装使用 `umask 077` 时暴露一个测试环境假设；权限拒绝用例现显式创建 0644 输入文件，不再依赖调用者的默认掩码。
- 交接专项：已测试原先停止的后台保持停止、初始化失败保留交还状态并能重试、PID 登记失败清理未放行子进程；回复覆盖顺序、防重、正文冲突、发送后确认失败和恢复。
- 独立只读审查完成。贡献指南补齐源码测试的包路径，并直接调用原生参数脚本的 zsh 入口。
- 原生参数与剪贴板恢复测试通过；未运行或更换实机助手构建。

## 新消息与交还闭环

用户从另一身份连续发来两条测试文本。CLI 分别按 `limit=1` 读到 cursor 33、34，识别为同一发送者的入站消息；只读时消费位置仍为 32。

| 检查 | 结果 |
| --- | --- |
| 先尝试回复后面的入站 | `earlier_incoming` 拒绝；消费位置、发件箱与 GUI 任务均不变 |
| 当前 Agent 回复第一条 | 7.929 秒完成本地出站核验；原 consumer 推进至 33，pending 清空 |
| 重复相同回复 / 改写相同来源正文 | 重复调用返回原结果；正文冲突拒绝；新增 GUI 任务为 0 |
| 交还正在使用的后台配置 | 就绪握手 0.173 秒；解除交互占用，原 consumer 继续 |
| 后台处理第二条 | 交还后 21.034 秒已完成本地出站核验；正确引用第一条提供的项目名称和课时；仅一次尝试 |
| 收件端 | 用户提供另一身份的聊天截图并确认两条均收到；截图中各出现一次 |
| 后台停止时直接读取 | 读取四条新事件，不启动后台、不推进消费位置 |
| 原先停止时接管再交还 | 交还后仍停止，消费位置保持 36 |

上述耗时为一次受控测试的观测值，不是性能保证。此轮没有通过重新发送或修改消费位置来修正结果。

## 无需回复

用户随后发送一条确认/感谢性质的入站文本，记录为 cursor 37。当前 Agent 通过 `chat skip` 写入原因并把原 consumer 从 36 推进至 37，消息正文仍保留在事件日志。再次执行相同 skip 返回已有结果。整个过程发件箱无新增、GUI 任务为 0，后台交接前无未决人工操作。

这是实际验证“读取并处理不要求发言”，不是用一条测试证明模型永远能正确判断该不该回复。当前实现没有按时间聚合所有群消息的调度器；连续聊天由调用 Agent 阅读后选择处理方式。

## 主动发送验收与最终状态

用户进一步授权在测试群主动发送验收消息。本轮使用已有 Rust outbox 主动发送接口提交两条不同正文，覆盖中文、英文、数字、表情及换行；内容均经本地出站核验，分别耗时 6.950 和 7.331 秒，每条仅一次 attempt。随后重复相同请求 ID 被底层拒绝，新增 GUI 任务为 0。这两条额外消息没有另取独立收件端确认，不与前述已收件的交接消息混同。

交还后最终观察：后台 `reading`，consumer 为 39，人工占用已解除，pending 为空，当前 outbox 无阻塞；没有对本账号主动发送的两条消息再次自动回复。后台运行时再按需读取不会中断它。两条旧历史不明记录数量未变。全部实机原始记录保留在私有运行目录；公开源只包含脱敏结论。

交付定位：已配置单群的受控真实使用。任意群/个人会话选择、首次无后台的高层人工初始化、逐会话模式注册表、多会话桌面调度和长期无人值守仍需后续实现或验收。

## 边界

旧发件箱中的两条不明结果保持原样；本轮不清理、不重发。接管只允许与当前待处理来源无关的历史记录继续保留；相关未决请求仍阻止交接。消息历史有界，`history_complete=false`。界面发送仍依赖微信登录、桌面可用、权限和窗口校验；读取来自加密副本，不依赖 OCR 识别消息正文。
