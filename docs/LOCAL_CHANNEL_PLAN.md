# 单群实现与下一步

当前主线是 [wx-cli 统一仓库](adr/0001-unified-repository.md)。Rust 负责事件和发件箱，Python 包负责运行器及派生需求笔记，Swift 负责图形发送，项目 skill 负责调用约定。MCP 暂不加入。

本轮交付见 [实施记录](../IMPLEMENTATION_PLAN.md)，代码结构见 [架构](architecture.md)，已验证范围见 [真实验证](REAL_READ_VALIDATION_20261015.md)。旧视觉原型保留为历史探索，不是当前读消息的实现。

后续按证据推进：

1. 在保持旧运行端可回退的前提下，安排新安装包与需求笔记的现场升级验收。
2. 验证更长时间运行、人工接管、真实断线、桌面重启后的恢复。
3. 若单群稳定，再增加第二个群的独立绑定与共享桌面发送调度。
4. 若 Agent 客户端确实需要工具发现，再提供复用同一状态的 MCP。

长期自动摘要需要单独设计候选事实、确认和冲突处理，当前不会把 LLM 自动提取当作已确认需求。
