# 交互式测试群接入

目标：在同一绑定群中，用 skill + CLI 完成找群、选择、分页读取、一次回复、接管与交还。后台和交互入口共用 Rust 事件、消费游标与发件箱，不新增消息数据库。

| 交付 | 验收条件 | 状态 |
| --- | --- | --- |
| 群元数据发现 | 只复制联系人/会话加密库，不访问消息分片；同名返回候选，不自动选群 | 已实现；实机精确发现通过 |
| 交互 CLI | 精确选择现有绑定；读取不确认消费；回复连续处理且 ID 稳定 | 已实现；分页与选群实测通过，真实新消息回复待测 |
| 接管/交还 | 等后台退出后独占；未决发送拒绝接管；交还保留原消费进度 | 已实现；接管和启动隔离实测通过，带消息交还待测 |
| 安装和实测 | 私有备份、保留原生助手；测试群读写、重复请求、交还恢复有证据 | 已部署 0.2.0；读写交接闭环进行中 |

本期选择只确认当前配置已有的群绑定，不自动创建其他群的运行器或发送配置。`select` 不等于把当前状态目录换绑。新群注册、多群并发调度、MCP 不属于本期。

接管采用安全退出后台进程、持久交互占用标记和操作锁；不把发出 pause 请求等同于已经暂停。遇原 pending 或未知发送结果停住并保留证据，不取消或重发。交互回复与后台使用相同源消息请求 ID，确认消费时核验原游标，拒绝跳过更早的待处理入站。

实测数据、配置、备份与原始日志只保存在私有忽略目录；公开文档记录脱敏结论。本次授权范围是既有测试群。

验证证据与剩余步骤见 [本轮测试记录](INTERACTIVE_VALIDATION_20261016.md)。
