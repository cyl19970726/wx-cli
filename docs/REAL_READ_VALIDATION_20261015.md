# 单群真实验证范围

本页为公开脱敏摘要。原始账号、群 ID、消息正文、截图、配置与运行日志留在私有目录，不随仓库发布。日期为 2026-10-15 至 2026-10-16。

| 能力 | 已观察证据 | 不能推出的结论 |
| --- | --- | --- |
| 加密副本读取 | 正确识别测试群、发送者与方向；重复扫描无重复新事件；明确确认后续读 | 全部历史、所有账号及版本都覆盖 |
| 普通文本发送 | 中文、换行和 emoji；部分消息获另一身份手机确认 | 任意长度或媒体发送 |
| 两轮真实 Agent 回复 | 需求追问与跨运行器重启的近期上下文回忆；第一轮独立收件确认 | 所有后续消息均已送达 |
| 连续有界运行 | 修复后同进程运行 1936.824 秒；4 入站对应 4 回复，未见重复或错误状态 | 24 小时稳定或客户上线 |
| 积压恢复 | CLI 读取入口暂不可用期间有新入站；恢复后同进程仅补回一次 | 切断实际 Wi-Fi 或任意断网均可恢复 |
| 连续消息 | 两条入站间隔约 8 秒，均早于首条回复；按顺序回复并综合此前需求 | 高吞吐或无限队列 |
| 进程恢复 | 正常停止 exit 0，pending 空、临时快照清理；同配置重启后游标与发件箱不变 | 操作系统重启后自动恢复 |
| 异常停发 | 错 PID、窗口尺寸、读取失败、重复请求、非空草稿拒绝；剪贴板不可读取时提交前停发 | 自动绕过桌面权限或账号限制 |

四条新增自动回复只核验到本地 `ui_observed`，没有新增独立收件确认。连续消息的两条观测延时约 20 秒和 41 秒，后一条包含排队；不是延时 SLA。

## 已修复的问题

- 长暂停超过轮询期限后出现负数等待。修复并回归，再次实机暂停 30 秒后恢复。
- 底层 CLI 不可执行时控制器也拒绝 status/stop。将启动依赖检查与管理入口分开，故障期间实测状态仍可读。
- 草稿探针留下自己的不可读富文本剪贴板残留。只核验并清理该自有合成残留；未清理普通用户剪贴板。原不明发送请求未重放。

早期发送曾发生本机切换会话后消息消失而收件端可见；因果尚未证明。后续坚持加密文件副本读取，新的对照消息在收件端和本机切回后都保留。账号退出与网络异常曾观察到，不能断言由自动化导致，也不能宣称已消除账号风险。
